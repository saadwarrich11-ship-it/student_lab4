# Environment comparison

| Tool | Purpose |
|---|---|
| pip | Installs Python packages |
| venv | Isolates project Python packages |
| Conda | Manages environments and packages, including non-Python dependencies |

Google Colab is useful when a browser-based notebook or shared compute is needed.
Local Jupyter is useful for offline work, local files, and a controlled virtual environment.

Conda demo command: `conda create -n demo python=3.11` then `conda activate demo` and `python --version`. Actual output depends on the installed environment; this demo was not executed here.
